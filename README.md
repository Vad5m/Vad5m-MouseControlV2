# Vad5m-MouseControlV2

> [!NOTE]
> **PC** </br>
> If you're on Windows, download the .exe file from the releases and run it as administrator. If you're on Linux, download .appimage or other types of applications, depending on what suits you best.
</br>
</br>

> [!NOTE]
> **Android**  </br>
> Download the .apk file from the releases on your phone, install it, then launch it and enter the numbers at the top from the application on your PC.
</br>
</br>

> [!WARNING]
> **Below are instructions on how to run it from their own code.**
</br>
</br>


> [!NOTE]
> **Linux**

```bash
# Installing dependencies
pip install -r requirements.txt

# Launching the application
python3 main.py
```
</br>
</br>

> [!NOTE]
> **Windows**

```
pip install flask pyautogui PyQt5

# windows Launching the application
sudo python3 main.py
```

</br>
</br>
