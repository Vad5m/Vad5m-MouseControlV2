# Vad5m-MouseControlV2

> **Linux**

```bash
# Installing dependencies
pip install -r requirements.txt

# Launching the application
python3 main.py
```
> **Windows**

```
pip install flask pyautogui

# windows Launching the application
sudo python3 win-mouse.py
```
